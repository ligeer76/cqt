## 2. 我会按什么顺序改写（适配你的坐标与 C 网格）

### Phase A：先抽象“深大气度量因子层”

在不立即重写方程的前提下，先引入一个统一模块（建议名 `deepatmo_metrics`），输出按垂直层的因子：

- `gradh(k)`：水平梯度修正
- `divh(k)`：水平散度修正
- `divz_u(k), divz_l(k)`：垂直通量散度上下界面系数
- `vol(k)`：控制体体积修正
- `invr(k)`：`1/r` 修正

这样你的现有通量框架只要在关键位置“乘因子”，就能先跑通。

### Phase B：把“控制体随高膨胀”接到质量与 tracer 更新

对 C 网格守恒更新，优先替换成：

- 质量（或 `rho*layer_thickness`）更新中的垂直散度项使用 `divz_u/divz_l`
- 体积分（airmass、全局守恒诊断）统一乘 `vol(k)`

这是最小侵入、收益最大的步骤。

### Phase C：改水平算子与动力项

把深大气修正系统地接入：

- 压力梯度力与水平梯度：乘 `gradh(k)` 或等效半层版本
- 曲率/几何项：显式引入 `1/r` 相关项（通过 `invr(k)`）
- 科氏与球面几何一致性：检查你当前“浅大气近似”残留项

### Phase D：压力坐标-几何高度闭合

因为你是**干静力压坐标 + 地形追随**，必须加一层稳定闭合：

- 给出 `p -> z/Φ` 的一致诊断路径
- 明确 `g` 取常量还是 `g(r)=g0(a/r)^2`
- 固化在同一时间步中的调用顺序（避免旧几何量和新状态混用）

## 3. 对你这类模型最容易出错的 8 个点

1. 只改动量不改质量通量散度（会破坏守恒）
2. `vol(k)` 用在诊断里但没用在守恒更新里（假守恒）
3. 半层/整层索引错位（`k` vs `k+1/2`）
4. C 网格上 `u/v` 点和标量点的 `r`、`gradh` 插值不一致
5. 地形追随项与深大气项重复计入
6. 顶层边界条件沿用浅大气写法导致反射增强
7. 仍用常量 `g` 但在其他项中用了 `1/r`（物理不闭合）
8. 水平-垂直分裂步中，某个子步忘记乘 deep-atmo 因子
